# بسته نوت‌بوک‌های تحلیل آماری — درس شناسایی الگو

برای **CommonsenseQA** و **ARC-Challenge** بر اساس پروژه «تشخیص شکست‌های پنهان تخمینگرهای عدم‌قطعیت تحت تغییر توزیع».

## نصب

```bash
python -m pip install -r requirements.txt
```

فایل‌های `.ipynb` را در همان پوشه‌ای کپی کنید که `datasets` در آن قرار دارد:

```text
project/
├── 01_prepare_numeric_features.ipynb
├── 02_statistics_and_distributions.ipynb
├── 03_three_normalizations.ipynb
├── 04_pearson_bbn_classification.ipynb
└── datasets/
    ├── commonsense_qa/
    └── arc_challenge/
```

نوت‌بوک‌ها را **به همین ترتیب** با Jupyter یا VS Code اجرا کنید؛ دکمه Run All هر نوت‌بوک کافی است.

**01:** فقط Parquetهای لوکال را می‌خواند، تعداد سؤال‌ها و گزینه‌ها را بررسی می‌کند و چهار ویژگی عددی استخراج می‌کند؛ خروجی `outputs/numeric_features.csv`.

**02:** Range، Min/Max، Mean، Median، Q1/Q2/Q3 و Q4 (بازه Q3 تا Max)، انحراف معیار، هیستوگرام، منحنی تجربی و نرمال، مرزهای ±۱/۲/۳σ و درصد واقعی در مقابل 68.27/95.45/99.73 را محاسبه و نمودارها را در `outputs/charts` ذخیره می‌کند.

**03:** Min-Max، Z-Score و Decimal Scaling را اعمال می‌کند؛ مقیاس‌دهنده‌ها به‌طور پیش‌فرض روی train برازش می‌شوند و به validation/test اعمال می‌شوند. جدول مقایسه و نمودار خروجی تولید می‌کند.

**04:** همبستگی پیرسون (Pearson Correlation) بین ویژگی‌ها، پیاده‌سازی شبکه بیزی (BBN) گسسته با پارامترهای برآوردشده از Train با هموارسازی لاپلاس، طبقه‌بندی دوتایی تشخیص منشأ دیتاست روی داده‌های Test و تولید ماتریس درهم‌ریختگی (Confusion Matrix) و گزارش کارایی در `outputs/classification`. این نوت‌بوک به خروجی نوت‌بوک ۱ یعنی `outputs/numeric_features.csv` (یا `outputs.zip`) وابسته است.

## نکات

- نصب `pyarrow` برای خواندن فایل Parquet لازم است.
- هیچ کدام از مراحل نیازمند GPU یا اینترنت نیستند (پس از نصب کتابخانه‌ها و دانلود دیتاست‌ها).
- فایل‌های خام تغییر نمی‌کنند.
- شمارش کلمات مستقل از tokenizer مدل است. برای ویژگی‌های احتمال و عدم‌قطعیت مثل `p_max`، `H_norm`، Margin، Agreement و Order Stability به یک فاز دیگر با اجرای LLM نیاز است.
- چون **اسلاید ۳۹** در فایل موجود نبود، در نوت‌بوک دوم قانون درصدها را بر اساس فرض **68–95–99.7** قرار دادیم.
- اگر مسیر دانلود شما با بالا فرق دارد، در سلول `DATASET_DIRS` در نوت‌بوک اول آن را تغییر دهید.
- آزمایش روی دیتاست واقعی فقط پس از اینکه فایل‌های Parquet را کنار نوت‌بوک‌ها بگذارید قابل اجراست؛ این بسته شامل خود دیتاست‌ها نیست.
